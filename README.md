## How to deploy on GitHub Pages

1. Upload **everything** above to the root of your repo
2. Make sure the `assets/images/` folder is included
3. Enable GitHub Pages (Settings → Pages → Deploy from main branch)
4. Visit: https://kyaraezstudio.github.io/KYAR-scents/
